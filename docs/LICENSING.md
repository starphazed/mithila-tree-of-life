## Files to retain

- Source distributions: include the root `LICENSE`, `THIRD_PARTY_NOTICES.md`, README and reference documentation.
- Static-site distributions: retain `dist/LICENSE` and `dist/THIRD_PARTY_NOTICES.md` when copying `dist/` to a host. The license copy is identical to the root file; the deployment notices use paths relative to `dist/`.
- Preserve existing upstream notices when changing the drawing engine or packaging it elsewhere. A new project license does not replace those terms.

The package's `private: true` setting prevents accidental npm publication. It does not change the MIT grant or GitHub repository visibility.
