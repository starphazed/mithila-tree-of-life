# Changelog

## MIT licensing — 2026-10-17

- Added the MIT License with copyright credited to starphazed.
- Updated the README, package metadata and licensing documentation.
- Included the license and third-party notices in the deployable `dist/` folder.
- Preserved cultural, artistic, scientific and algorithm credits and upstream terms.

Application 4.1.1, generator 4 and motion 2 are unchanged.

## Documentation update — 2026-10-17

- Added troubleshooting for faint wind, cached-view softness and stalls at the end of drawing.
- Summarized the recorded desktop performance limits beside the Pi setup instructions.
- Clarified motion-version imports, replay behavior and fixed-pose inspection.
- Added a licensing guide covering the root license file, README, package metadata, credits and artwork scope.

Application 4.1.1, generator 4 and motion 2 are unchanged by this documentation update.

## 4.1.1 — 2026-10-17

- Kept paper, border and ground in a stationary vector layer after drawing.
- Preserved native display density within a bounded canvas pixel budget and removed the extra low-resolution sprite resampling pass.
- Strengthened secondary-branch response and individual leaf flutter while retaining subtle trunk, lotus and animal motion.
- Updated primary contours more frequently so their junctions follow the stronger wind.
- Added fitted-size motion and HiDPI regression checks, plus fixed-pose visual inspection in the device fixture.

Composition remains generator 4. Motion calibration is version 2, recorded in sessions and exported SVG metadata; older sessions use the current calibration.

## 4.1.0 — 2026-10-17

- Added conservative collision bounds and background composition while preserving generator-4 paintings.
- Sized screen caches to the display, cached rigid twigs and separated articulated motif layers.
- Cached completed motifs during growth without PNG encoding; kept vectors for inspection and export.
- Stopped idle animation polling and repeated status updates after growth.
- Added automatic constrained-device rendering, an explicit Pi 4 URL, device benchmarks and a setup guide.

The Pi 4 target is 4 GB at 1080p. Physical Pi validation remains pending.

## 4.0.3 — 2026-10-17

- Added named artistic, scientific and algorithm credits in the README and About panel.
- Identified the A–U branching reference as Figure 1 in Sun et al. (2010), with all six authors and its DOI.
- Added third-party notices and source comments for Mulberry32 and FNV hashing.

Generator version and seeded output remain unchanged.

## 4.0.2 — 2026-10-16

- Removed slogans, repeated explanations and the long in-app process essay.
- Simplified navigation, playback states, motif descriptions and download dialogs.
- Kept a short About panel with keyboard controls and references, accessible on mobile.
- Added setup, generation, development, validation and reference documentation with review images.
- Excluded local hosting state and generated artifacts from source uploads.

Generator version remains 4. Artwork construction and animation behavior are unchanged.

## 4.0.1

- Expanded borders to twelve seeded pattern families with varying repeats and corners.
- Reduced SVG updates during drawing and added cached rendering for completed motion.
- Preserved full vector detail for close zoom and exports.

## 4.0.0

- Made the seed the primary artistic control and removed custom parameter controls.
- Added coordinated composition recipes, broader palette systems and independent random streams.
- Added procedural lotus, peacock and fish families, hierarchical wind and seed-only sessions.
- Fitted progressive drawing to a seed-selected duration of 10–15 seconds.
